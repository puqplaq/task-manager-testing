# Task Manager

Небольшое REST API приложение для управления задачами, написанное на **FastAPI**. Данные хранятся в памяти (database-free).

## Возможности

- Создание, просмотр, обновление и удаление задач
- Интерактивная документация API (Swagger UI)
- Полноценный набор тестов: unit, integration, contract и e2e
- Проверка качества кода: `ruff` и `mypy`
- Генерация отчётов о покрытии кода и отчётов Allure

## Требования

- **Python** >= 3.11
- **Poetry**

> Проверить наличие Poetry можно с помощью команды:
>
> ```bash
> poetry --version
> ```

## Установка

Склонировать репозиторий:

```bash
git clone <url-репозитория>
cd task-manager-tests
```

Установить зависимости:

```bash
make install
```

или напрямую через Poetry:

```bash
poetry install
```

## Запуск приложения

Запустить сервер в режиме разработки с auto-reloading:

```bash
make run
```

или напрямую через Poetry:

```bash
poetry run uvicorn app.main:app --reload
```

После запуска приложение будет доступно по адресу:

- Приложение (API): <http://127.0.0.1:8000>
- Swagger UI (документация): <http://127.0.0.1:8000/docs>
- ReDoc: <http://127.0.0.1:8000/redoc>

## Доступные endpoints

Префикс — `/tasks`:

| Метод   | Маршрут           | Описание                     |
|---------|-------------------|------------------------------|
| `GET`   | `/tasks`          | Список всех задач            |
| `POST`  | `/tasks`          | Создать новую задачу         |
| `GET`   | `/tasks/{id}`     | Получить задачу по ID        |
| `PATCH` | `/tasks/{id}`     | Обновить задачу по ID        |
| `DELETE`| `/tasks/{id}`     | Удалить задачу по ID         |

Пример создания задачи:

```bash
curl -X POST http://127.0.0.1:8000/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "Test Task #1", "description": "Test task description"}'
```

## Запуск тестов

Запуск всех тестов:

```bash
make test
```

или напрямую:

```bash
poetry run pytest tests/ -v
```

Проект содержит следующие категории тестов:

- `tests/unit/` — модульные тесты
- `tests/integration/` — интеграционные тесты
- `tests/contract/` — контрактные тесты
- `tests/e2e/` — сквозные (end-to-end) тесты
- `tests/load/` — нагрузочные тесты

### Покрытие кода

Запуск тестов с проверкой покрытия и формированием HTML-отчёта:

```bash
make test-cov
```

Отчёт будет сгенерирован в директории `htmlcov/`.

### Отчёт Allure

Запуск тестов с формированием отчёта Allure:

```bash
make test-allure
```

Для генерации HTML-отчёта требуется установленный CLI-инструмент **Allure**.

Запуск нагрузочных тестов с использованием `locust`:

```bash
make run
make test-load
```

## Линтинг и проверка типов

Проверка стиля кода (`ruff`) и статическая проверка типов (`mypy`):

```bash
make lint
```

Автоматическое исправление ошибок стиля:

```bash
make fix
```

Форматирование кода:

```bash
make format
```

## Очистка артефактов

Удаление кэша и сгенерированных артефактов (тестовые отчёты, кэши):

```bash
make clean
```

## Команды Makefile

| Команда      | Описание                                        |
|--------------|-------------------------------------------------|
| `make install`    | Установка зависимостей                     |
| `make run`        | Запуск сервера (dev-режим)                 |
| `make test`       | Запуск всех тестов                         |
| `make test-cov`   | Запуск тестов с покрытием (HTML-отчёт)     |
| `make test-allure`| Запуск тестов и генерация отчёта Allure    |
| `make test-load`  | Запуск нагрузочных locust-тестов           |
| `make lint`       | Проверка `ruff` + `mypy`                   |
| `make fix`        | Авто-исправление ошибок `ruff`             |
| `make format`     | Форматирование кода                        |
| `make lock`       | Обновление `poetry.lock`                   |
| `make clean`      | Очистка кэша и артефактов                  |
